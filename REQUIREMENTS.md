# Godot Project Requirements

## Minimum Godot Version
- Godot 4.0 or later
- Godot 4.3 recommended (latest stable)

## Tested On
- Godot 4.2+
- Windows, macOS, Linux

## Android Requirements
- Android SDK (API level 21+)
- Android NDK (recommended for native performance)
- Java Development Kit (JDK)
- Keystore for signing APK

## System Requirements
- 2GB RAM minimum
- 100MB free disk space
- Any modern CPU

## Mobile Device Requirements
- Android 6.0+ (API 21+)
- 100MB free storage
- Minimum 1GB RAM

## Project Settings

The project is pre-configured with:
- Mobile renderer
- Touch input support
- 1080x1920 viewport (standard phone)
- Canvas-based UI (no heavy 3D)
- Optimized for 60 FPS

## Build Size

Expected APK size: 30-50MB (base project)
With assets added: 50-100MB

## Performance

Target: 60 FPS on mid-range Android devices
Memory usage: ~50-80MB at runtime
