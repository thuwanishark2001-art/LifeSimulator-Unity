# Life Simulator - Quick Start

## Running in Godot

1. Extract this ZIP folder
2. Open Godot 4.x
3. Import this folder as a project
4. Open `scenes/MainGame.tscn`
5. Press F5 or click Play

## Game Controls

All interactions are button-based on the main screen:

**Row 1 (Top Actions):**
- Work: Earn money, advance job level
- Eat: Reduce hunger, cost money
- Sleep: Reset day, restore energy
- Relax: Boost happiness

**Row 2 (Self-Care):**
- Shower: Increase cleanliness
- Social: Increase social level and happiness
- Study: Increase skill level
- Workout: Increase fitness and health

**Row 3 (Special):**
- Meditate: Big happiness boost
- Shop: Spend money for happiness
- Home+: Upgrade home quality (costs $50)
- Save: Manual save to current slot

## Game Features

✓ Real-time stat degradation
✓ Job progression system (Freelancer → Senior → Manager → Executive)
✓ Home quality upgrades
✓ Fitness tracking
✓ Achievement system
✓ Multiple save slots
✓ Auto-save every 30 seconds
✓ Day counter and time progression
✓ Status alerts and warnings
✓ Color-coded health bars (green/yellow/red)

## Stats to manage

- Energy (decreases over time)
- Hunger (decreases over time)
- Happiness (core happiness level)
- Cleanliness (hygiene level)
- Health (overall well-being)
- Money (currency for purchases)
