# Godot Android Export Checklist

1. Install Godot 4.x and Android build templates.
2. Configure Android SDK and JDK in Godot Editor.
3. In Project > Export > Android > Add preset.
4. Select APK or AAB build.
5. Set package name, version, and keystore.
6. Test on real Android device before publishing.
7. Disable unnecessary debug features before release.
8. Keep UI optimized for mobile resolutions.
